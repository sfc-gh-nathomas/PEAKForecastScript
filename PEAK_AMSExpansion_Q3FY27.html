Model Methodology

M1 — Pipeline Risk

Binary risk classification against 53 days of runway (53 days left in Q3 FY27). Good = days_in_stage + 53 ≥ threshold. Stage 5: 79d. Stage 4: 104d. Stage 1–3: 146d. Commit = deployed + Stage 5+6. ML = commit + all good pipeline. Stretch = deployed + total pipeline. As the quarter runs down the runway shrinks, so the same UC can move from good to at-risk without changing stage. Backtest avg error: 22.8%

M2 — Historical Pacing

Extrapolates from $64.2M already banked. Prior quarters had reached 34.8% of final deployed ACV by day 40 (range 32.1–36.2%), so ML = deployed ÷ 0.348. Tight historical spread makes this the most stable model at this point in the quarter.

M3 — Stage Conversion

IMP 63.9% + TW 37.8% + Pre-TW 17.8%, applied to milestone-dated buckets and added to deployed ACV, then ÷ (1 − 23.0%) to gross up for pipeline not yet visible. Commit uses min rates ÷ (1 − 19.5%). Stretch = deployed + total pipeline (capped). Rates calibrated at this report's own time horizon from Q3/Q4 FY26 + Q1/Q2 FY27, most recent quarter double-weighted. LOO backtest avg error: 21.5%

M4 — Weighted Ensemble

Dashboard weights with all three models live: M1 51%, M2 10%, M3 40%. Applied identically to all 8 regions.

Target gap (AMSExpansion): M4 ML ($187.8M) -2.0M vs target ($189.8M). M4 Stretch ($209.4M) exceeds target by 19.6M.
M1 vs M3 divergence note: M1 and M3 are nearly equal in accuracy (22.8% vs 21.5% LOO error), so M4 weights them almost equally. M1 tends to overpredict in high-pipeline quarters (Q4 FY26: +25.7%, Q1 FY27: +37.5%) while M3 tends to underpredict in low-pipeline/high-new-pipeline quarters (Q3 FY26: −27.2%). The ensemble corrects for both biases.
