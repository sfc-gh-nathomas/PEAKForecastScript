Model Methodology

M1 — Pipeline Risk

Binary risk classification against 92 days of runway (full quarter). Good = days_in_stage + 92 ≥ threshold. Stage 5: 79d. Stage 4: 104d. Stage 1–3: 146d. Commit = deployed + Stage 5+6. ML = commit + all good pipeline. Stretch = deployed + total pipeline. As the quarter runs down the runway shrinks, so the same UC can move from good to at-risk without changing stage. Backtest avg error: 22.8%

M2 — Historical Pacing

Requires deployed ACV as the denominator. Deployed = $0 until Q4 FY27 opens Nov 1. Weight redistributed to M1/M3.

M3 — Stage Conversion

IMP 44.0% + TW 27.7% + Pre-TW 14.8%, applied to milestone-dated buckets and added to deployed ACV, then ÷ (1 − 63.3%) to gross up for pipeline not yet visible. Commit uses min rates ÷ (1 − 54.7%). Stretch = deployed + total pipeline (capped). Rates calibrated at this report's own time horizon from Q3/Q4 FY26 + Q1/Q2 FY27, most recent quarter double-weighted. LOO backtest avg error: 21.5%

M4 — Weighted Ensemble

M2 contributes nothing because the quarter has not opened, so its 10% weight is redistributed proportionally across M1 and M3 — M1 56.0%, M3 44.0% — keeping the ensemble at 100%. Applied identically to all 8 regions.

Target gap (AMSExpansion): M4 ML ($196.1M) +6.3M vs target ($189.8M). M4 Stretch ($256.2M) exceeds target by 66.4M.
M1 vs M3 divergence note: M1 and M3 are nearly equal in accuracy (22.8% vs 21.5% LOO error), so M4 weights them almost equally. M1 tends to overpredict in high-pipeline quarters (Q4 FY26: +25.7%, Q1 FY27: +37.5%) while M3 tends to underpredict in low-pipeline/high-new-pipeline quarters (Q3 FY26: −27.2%). The ensemble corrects for both biases.
